Connexions pour les statistiques

Guide des connexions (tout est gratuit)

Twitch (découverte des streamers) : va sur dev.twitch.tv/console → « Register Your Application » → URL de redirection http://localhost → copie le Client ID et génère un Client Secret.

YouTube : dans console.cloud.google.com, crée un projet, active « YouTube Data API v3 », crée un identifiant OAuth de type « Application de bureau », télécharge le JSON et renomme-le youtube_client_secret.json dans le dossier data, puis clique sur « Connecter YouTube ». La connexion autorise l'envoi des vidéos et la lecture des statistiques.

TikTok : app sur developers.tiktok.com avec « Content Posting API » et « Login Kit ». Coche les scopes video.publish, user.info.stats et video.list, puis lance Connecter TikTok.bat. Tant que TikTok n'a pas validé ton app, les vidéos sont publiées en privé.

Instagram : compte professionnel relié à une page Facebook, app sur developers.facebook.com avec les permissions instagram_content_publish et, pour les vues des Reels, instagram_manage_insights. Renseigne l'ID utilisateur Instagram et le jeton longue durée.

Musique de fond : dépose des musiques libres de droits dans assets\music.
