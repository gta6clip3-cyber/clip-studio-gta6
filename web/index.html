Guide des connexions (tout est gratuit)

Twitch (découverte des streamers) : va sur dev.twitch.tv/console → « Register Your Application » → URL de redirection http://localhost → copie le Client ID et génère un Client Secret.

YouTube : dans console.cloud.google.com, crée un projet, active « YouTube Data API v3 », crée un identifiant OAuth de type « Application de bureau », télécharge le JSON et renomme-le youtube_client_secret.json dans le dossier data, puis clique sur « Connecter YouTube ». Une clé API (même console) sert à trouver les lives YouTube.

TikTok : crée une app sur developers.tiktok.com avec le produit « Content Posting API » (scope video.publish). Tant que TikTok n'a pas validé ton app, les vidéos sont publiées en privé (SELF_ONLY).

Instagram : compte Instagram professionnel relié à une page Facebook, app sur developers.facebook.com avec « Instagram Graph API » (permissions instagram_content_publish). Renseigne l'ID utilisateur Instagram et le jeton longue durée.

Musique de fond : dépose des musiques libres de droits dans assets\music. Elles sont baissées automatiquement quand le streamer parle.
